# BPMN Viewer

Небольшое веб-приложение на Python с FastAPI, которое отображает BPMN-диаграмму в браузере.

Для визуализации используется библиотека `bpmn-js`.

В проекте открывается файл `sample.bpmn`. Это доработанная версия исходного `primer.bpmn` из тестового задания: сама диаграмма осталась той же, но расположение элементов было немного поправлено для более аккуратного отображения.

## Что делает проект

- поднимает простой бекенд на FastAPI;
- отдаёт HTML-страницу со viewer;
- загружает BPMN-диаграмму с сервера и отображает её в браузере.

## Запуск

Требуется Python 3.10+.

Из папки корня репозитория:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload
```

После запуска страница будет доступна по адресу `http://127.0.0.1:8000`.
